# 想点子指南

> 先低成本发散，再逐步提高证据投入。生成阶段不声称新颖。

## 漏斗

```text
待评估点子.md (inbox)
        ↓ 去重、合并、澄清问题
索引.md (分配 IDEA-YYYY-NNNN，状态：初筛)
        ↓ 四项硬门槛
评估中 (检索 + 最小可否证探针 + 评分 v2)
        ↓
进行中 / 搁置 / 拒绝 / 重复 / 已取代
        ↓
已完成 / 已放弃
```

## 七种生成方法

1. 组合创新：只有发生必要且非平凡的相互作用才算候选贡献。
2. 弱点三角验证：用综述、失败案例、实践需求等至少两类证据确认问题。
3. 方法移植：检查源方法假设在目标领域是否成立。
4. 理论深挖：寻找存在性、唯一性、可识别性、收敛性、稳健性等基础问题。
5. 边界与假设挑战：把默认假设推到现实边界或直接违反它。
6. 引文链缺口挖掘：从明确 gap 出发检查后续引用是否已经解决。
7. 目标反向推导：从可验证目标倒推必要依赖，并检验缺失部分是否具有一般科学价值。

详细步骤见 skill 的 `references/idea-generation-methods.md`。

## 初筛硬门槛

- 问题重要性：回答后会改变什么？
- 可回答/可证伪性：什么结果会推翻或限制主张？
- 资源可达性：数据、理论前提、工具、时间、权限是否有路径？
- 伦理与治理：隐私、同意、安全、双重用途、许可是否可接受？

关键门槛为 `No` 时停止；为 `Unknown` 时先设计一个有时间预算的探针。

## 文件规则

- inbox 可以粗糙，但升级到索引前必须去重。
- 索引是唯一生命周期真相源。
- 白皮书只引用 evidence ID，不复制 evidence 行。
- 新评估文件夹优先命名为 `[IDEA-ID] [短标题]`。
- 迁移旧项目时保留原文件夹名，除非明确要求重命名。
