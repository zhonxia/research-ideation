# 想点子指南

> 发散方法论。可扩展——学了新思路就补充在这里。

## 工作流

```
想点子指南.md（方法论）
        ↓ 按思路发散
碎片想法 → 待评估点子.md（收集池）──→ 索引.md（登记，状态：待评估）
                ↓ 调研
02-评估中/[点子名]/（评估白皮书）
                ↓ 更新状态
索引.md（待评估 → 评估中）
```

## 使用方式

1. 灵感来了 → 扔进 `01-灵感收集` 的「待评估点子.md」
2. 定期回顾 → 选择感兴趣的点子进行调研评估
3. 评估完成 → 在 `02-评估中` 创建独立文件夹和评估白皮书
4. 评估通过 → 移到 `03-进行中`，拆成具体任务
5. 完成/放弃 → 移到 `04-已归档`，写一句总结

## 文件规范

- **一个点子一个文件夹**，文件夹名即点子标题
- 每个评估包含：评估白皮书（含评分、文献调研、技术可行性分析）
- 索引中记录所有已有点子，按创建时间倒序排列
