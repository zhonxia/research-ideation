# README — IDEA 管理系统

## 文件职责

### `想点子指南.md`
- **职责**：想点子的方法论文档
- 记录发散思路（组合创新、补短板、搬方法、理论深挖、边界极限法、文献解构法）
- 你教我新的思路时补充到这里
- 按照文档中的方法发散后，结果记录到「待评估点子.md」

### `待评估点子.md`
- **职责**：点子的收集池，记录尚未调研的灵感/想法
- 只需一行描述即可，不需要详细调研
- 格式自由，想到什么写什么
- 调研后会拆分为独立的评估文件

### `索引.md`
- **职责**：已有点子文件目录 + 文献已有研究方向索引（二合一）
- 点子目录：快速浏览已有哪些点子、避免重复
- 文献索引：文献库的研究方向分类，用于新颖性验证

### 流转关系

```
想点子指南.md（方法论）
        ↓ 按思路发散
碎片想法 → 待评估点子.md（收集池）
                ↓ 调研
独立评估文件夹（一个点子一个） → 索引.md（登记）
```

## 使用方式

1. 灵感来了 → 扔进 `01-灵感收集` 的「待评估点子.md」
2. 定期回顾 → 选择感兴趣的点子进行调研评估
3. 评估完成 → 在 `02-评估中` 创建独立文件夹和评估白皮书
4. 评估通过 → 移到 `03-进行中`，拆成具体任务
5. 完成/放弃 → 移到 `04-已归档`，写一句总结

## 文件规范

- **一个点子一个文件夹**，文件夹名即点子标题
- 每个评估包含：评估白皮书（含评分、文献调研、技术可行性分析）
- 索引中记录所有已有点子，按创建时间倒序排列
