# IDEA 研究点子系统

本目录使用分阶段漏斗管理研究点子：

```text
Inbox → 去重 → 初筛 → 评估 → 最小探针 → 进行中
                    ↘ 拒绝       ↘ 搁置 / 重复 / 已取代
```

## 文件职责

| 路径 | 职责 |
|---|---|
| `01-灵感收集/待评估点子.md` | 临时 inbox，允许未经整理的想法 |
| `01-灵感收集/_研究点子卡模板.md` | 初筛后、正式评估前使用的轻量点子卡 |
| `01-灵感收集/索引.md` | 点子 ID 与生命周期的唯一真相源 |
| `01-灵感收集/evidence-log.md` | 检索证据和 claim-evidence 关联的唯一真相源 |
| `01-灵感收集/想点子指南.md` | 十一种生成方法与漏斗规则 |
| `01-灵感收集/问题结构图谱.md` | 目标领域问题及其抽象结构 |
| `02-评估中/` | 正在检索、验证或评分的点子 |
| `03-进行中/` | 已选择投入的研究 |
| `04-已归档/` | 搁置、拒绝、重复、取代、完成或放弃的工件 |
| `05-文献库/` | 每篇论文一个简明笔记 |
| `06-跨领域方法库/` | 来源领域覆盖、成熟方法卡、扫描与正负匹配记录 |

## 核心规则

1. 本地文献库没有覆盖，只能说明本地覆盖缺口。
2. 点子离开 inbox 时分配 `IDEA-YYYY-NNNN`，ID 永不复用。
3. 四项硬门槛通过后才评分。
4. 紧迫性不计入总分，只用于排程。
5. 白皮书引用 evidence ID，不复制 evidence 行。
6. 比较点子前确认评分版本和研究类型兼容。
7. 生命周期或证据变化后运行校验器。
8. 组合创新按问题结构匹配，并记录所有负匹配。
9. 新颖性核查先拆分主张，再宽搜、摘要初筛、全文核查最接近工作，并形成差异陈述。
